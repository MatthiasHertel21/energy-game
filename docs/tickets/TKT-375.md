# TKT-375 — KSE Schema And Validation For Interzonal Model Phase 1

- Typ: Applikation
- Priorität: P1
- Status: Planned

## Problem
The current scenario model supports zone count and ATC matrices, but it does not provide a complete, explicit model for zonal synthetic supply and demand, grid settlement settings, or configurable generator curtailment rules.

## Ziel
Extend scenario schema and validation so designers can configure Phase 1 interzonal behavior safely and consistently.

## Umsetzung
- Extend `environment.groups` with zonal distribution vectors for synthetic generation.
- Extend `market.consumer_mix` with zonal distribution vectors for synthetic demand.
- Add `grid.losses_pct_per_link`.
- Add `grid.network_settlement` with `extra_cost_mode`, `cost_allocation_target`, `shortfall_price_mode`, and `shortfall_price_value`.
- Add `grid.generator_curtailment_mode`.
- Add defaults for missing new fields to preserve backward compatibility.
- Treat `general.player_zone` as legacy fallback, not as the primary multi-zone model.
- Validate vector length, vector sum, numeric ranges, enum values, and zone references.

## Akzeptanzkriterien
- Scenarios can define zonal synthetic distributions for all configured zones inside existing `environment.groups` and `market.consumer_mix` structures.
- Validation rejects invalid percentage vectors and invalid enum values.
- Existing scenarios without the new fields remain loadable through sane defaults.
- Validation ensures player-type zones remain within configured zone range, with `general.player_zone` only supported as legacy fallback.

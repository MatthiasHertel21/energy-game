# TKT-376 — KSE UI For Interzonal Synthetic Distribution And Grid Settlement

- Typ: Applikation
- Priorität: P1
- Status: Planned

## Problem
Even with schema support, designers need a usable editor workflow to define zonal synthetic distributions and the new grid settlement rules without editing raw JSON.

## Ziel
Add KSE UI controls for Phase 1 interzonal scenario configuration.

## Umsetzung
- Add a new `Zone Distribution` tab to the existing synthetic producer and consumer editing flow.
- Provide editable per-zone percentage inputs with sum feedback.
- Bind synthetic generation editing to `environment.groups` and synthetic demand editing to `market.consumer_mix` instead of introducing a separate top-level model.
- Add grid settlement controls in the Grid tab for:
  - per-link losses,
  - shortfall pricing mode and value,
  - extra-cost allocation mode,
  - generator curtailment mode.
- Mark non-default settlement and curtailment options as advanced settings.
- Surface validation errors inline in KSE.

## Akzeptanzkriterien
- Designers can configure zonal synthetic distributions without raw JSON edits and without leaving the existing environment and demand editing structure.
- Designers can configure generator curtailment mode and shortfall pricing in the Grid tab.
- The UI prevents or clearly flags invalid percentage sums.
- Saved scenarios round-trip correctly through the KSE editor.

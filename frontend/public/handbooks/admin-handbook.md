# Admin Handbook
## Energy Market Simulation Game (EMSG)

Version: 1.0  
Date: 17 Nov 2025  
Audience: System Administrators

---

## Quick Guide

- Tabs: Users | Activity Dashboard | Sessions.
- Manage users/roles, invites, and review activity and sessions.
- Ops: ensure backups, logs/monitoring, and security hygiene.

---

## Users
- Change roles, invite users, reset passwords (policy enforced).

## Activity Dashboard
- Tiles + time series; filter by period; recent activity list.

## Sessions
- Filter by status/date; open trainer views; export if enabled.

## Operations
- Backups, centralised logs, HTTPS, CORS, rate limits, privacy.

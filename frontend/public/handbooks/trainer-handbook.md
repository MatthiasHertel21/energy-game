# Trainer Handbook
## Energy Market Simulation Game (EMSG)

Version: 1.0  
Date: 17 Nov 2025  
Audience: Trainers/Facilitators

---

## Quick Guide

- Trainer view: monitor participants, manage sessions, review results.
- Flow: Create/assign session → Brief participants → Monitor → Debrief with Evaluation/Replay.

---

## Participants Panel
- Shows list of players, type selection, connection status, last submission time.
- Auto-refresh every few seconds; search and filters for large cohorts.

## Sessions
- Start/pause/end rounds; set duration; freeze hours; broadcast announcements.
- Shared market: ensure all players selected a type before starting.

## Debriefing
- Use Evaluation (KPIs, tables, trends) and Replay (step through rounds).
- Export PDF/CSV/PNG for reporting.

## Tips
- Keep sessions focused; 2–4 player types; ≤3 scenario events.
- Do a dry-run; verify timers and freeze; have a backup plan.
